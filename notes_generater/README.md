# 课程笔记助手（GUI 用户手册）

## 1. 产品定位
课程笔记助手是一个本地运行的桌面 GUI 工具，用于把单门课程资料生成成中文讲义。

核心原则：
1. `一个项目 = 一门课程`。
2. 全程 GUI 操作，不要求你使用命令行。
3. 通过多轮 workflow（Round0/1/2/3/Final）生成、检查、修订讲义。

## 2. 新目录模型（单课程）
当你选择课程根目录（例如 `/.../ECE364`）后，系统固定使用：

1. 项目目录：`/.../ECE364/.notes_agent/project`
2. 笔记目录：`/.../ECE364/notes`

其中：
1. `.notes_agent/project` 里保存状态、日志、补丁和中间产物。
2. `notes` 里保存最终讲义与检查脚本。

## 3. 讲次模型（`lec_id`）
系统不假设“一讲一个文件夹”。

你需要在 GUI 里维护：
1. `lec_id`（例如 `LEC01`, `LEC02`）
2. 每个 `lec_id` 对应的资料路径列表（可包含目录和文件）

讲义默认输出到：
1. `notes/notes/lectures/<lec_id>.md`

## 4. 界面页面说明
左侧导航包含 6 个页面：

1. `项目`
2. `讲次`
3. `流程`
4. `审阅`
5. `提示词`
6. `运行记录`

### 4.1 项目页
用途：创建或加载当前课程项目。

字段与按钮：
1. `课程根目录`：选择课程所在目录。
2. `课程标识（可选）`：可手输；不填则用目录名自动生成。
3. `创建或加载项目`：若项目已存在则加载，否则创建。
4. `项目目录` / `笔记目录`：只读显示。

### 4.2 讲次页
用途：维护 `lec_id -> 资料路径` 映射。

字段与按钮：
1. `讲次列表`：查看已登记讲次及路径数。
2. `讲次标识`：填写或编辑 `lec_id`。
3. `资料路径`：每行一个路径。
4. `添加路径`：通过文件选择器追加路径。
5. `保存讲次映射`：写入当前讲次映射。
6. `删除讲次`：删除当前 `lec_id`。
7. `刷新列表`：重新读取注册表。

### 4.3 流程页
用途：执行轮次与恢复 workflow。

字段与按钮：
1. `起始轮次` / `结束轮次`
2. `目标讲次`：可留空；留空表示运行所有已登记 `lec_id`。
3. `最大改动行数` / `最大改动文件数`
4. `每轮后暂停`
5. `启用网页搜索`（仅在 Final + 允许外部参考时实际生效）
6. `初始化第 0 轮`
7. `执行流程`
8. `恢复流程`
9. `执行检查`

### 4.4 审阅页
用途：把人工反馈追加到 `review/feedback.md`。

### 4.5 提示词页
用途：查看和编辑各轮模板（Round1/2/3/Final/Repair）。

### 4.6 运行记录页
用途：查看历史、查看 patch、清理中间缓存。

按钮：
1. `列出运行记录`
2. `查看差异补丁`
3. `清除缓存`（仅删中间文件，不删已生成讲义）

## 5. 推荐使用流程（GUI）

### Step 1：创建课程项目
1. 打开 `项目` 页。
2. 选择课程根目录。
3. 点击 `创建或加载项目`。

### Step 2：配置讲次映射
1. 打开 `讲次` 页。
2. 输入 `lec_id`（例如 `LEC01`）。
3. 填入该讲次相关路径（可多行）。
4. 点击 `保存讲次映射`。
5. 对其他讲次重复以上步骤。

### Step 3：初始化 Round0
1. 打开 `流程` 页。
2. 点击 `初始化第 0 轮`。

### Step 4：执行主流程
1. 选择 `from/to`（例如 `round1 -> round3`）。
2. 目标讲次可留空（全量）或指定一个 `lec_id`。
3. 点击 `执行流程`。

### Step 5：审阅并收敛
1. 在 `审阅` 页写反馈并追加。
2. 回到 `流程` 页点击 `恢复流程` 跑后续轮次。
3. 到 `final` 轮收敛讲义结构、术语和速查内容。

## 6. 典型场景

### 场景 A：每讲一个文件夹
示例：
1. `LEC01 -> /.../ECE364/Lec1/`
2. `LEC02 -> /.../ECE364/Lec2/`

### 场景 B：所有讲次共用同一资料目录
示例：
1. `LEC01 -> /.../ECE364/materials/`
2. `LEC02 -> /.../ECE364/materials/`

### 场景 C：一个讲次由多来源组成
示例：
1. `LEC03 -> /.../slides/lec03/`
2. `LEC03 -> /.../code/lec03/`
3. `LEC03 -> /.../extra/lec03_notes.pdf`

## 7. 常见问题

### 7.1 执行前报“未配置可用讲次”
原因：还没有在 `讲次` 页保存任何映射。

处理：
1. 先到 `讲次` 页保存至少一个 `lec_id` 和对应路径。

### 7.2 为什么流程停在 `paused`
常见原因：
1. 你勾选了 `每轮后暂停`。
2. 改动超过阈值（行数/文件数）。

### 7.3 为什么看不到补丁
处理顺序：
1. 先点 `列出运行记录`。
2. 复制正确 `run_id`。
3. 再点 `查看差异补丁`。

## 8. 输出质量建议
1. 先小范围试跑一个 `lec_id`，确认风格再全量执行。
2. 利用 `提示词` 页微调各轮要求。
3. 在 Round2/Round3 后做人审，再进入 Final。
